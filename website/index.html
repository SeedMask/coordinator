Before you install

  • Export your watch-only key from SeedMask (Crypto → Export) before adding a wallet.
  • All signing happens on SeedMask hardware — this app never holds your seed.
  • Network settings (Bitcoin Core, Electrum, public APIs) are configurable in System settings.

Build from source

cd coordinator/electron
npm install
npm run release

Run npm run release on each target OS to produce platform-native installers.
